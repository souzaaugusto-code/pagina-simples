# 🌐 DAS Host - Landing Page

Uma landing page simples e responsiva para uma empresa de hospedagem de sites. Projeto prático para treinar a base de HTML, CSS e Responsividade.

## 🛠️ O que foi praticado:

###  HTML
*  Estrutura semântica (`<nav>`, `<main>`, `<section>`, `<footer>`).
*  Criação de formulários de contato e de busca de domínio.
*  Ícones integrados usando Font Awesome.

### CSS
*  Reset global de margens com `box-sizing`.
*  Alinhamento de elementos e cards usando Flexbox.
*  Uso de `position: absolute` e `relative` para organizar o menu do topo.
*  Efeitos de hover nos botões e links com `transition`.

### 📱 Responsividade
* Uso de `@media` queries para adaptar o site para múltiplos dispositivos.
* Quebra de layout com `flex-direction: column` para telas pequenas.
